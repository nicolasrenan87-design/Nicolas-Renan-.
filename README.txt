PROJETO DE VIDA — NICOLAS RENAN

Arquivos:
- index.html: estrutura e conteúdo do site
- style.css: aparência e layout responsivo
- script.js: menu mobile e ano automático

Como abrir no VS Code:
1. Extraia o arquivo ZIP.
2. Abra a pasta "projeto_vida_nicolas_renan" no VS Code.
3. Abra o arquivo index.html.
4. Clique com o botão direito e escolha "Open with Live Server" (se tiver a extensão).
   Também é possível abrir index.html diretamente no navegador.

Personalização:
Edite os textos no index.html para acrescentar informações reais, fotos e detalhes da trajetória.
A imagem de fundo usa um endereço externo do Unsplash e precisa de internet para carregar.

Observação:
O conteúdo apresenta um objetivo de carreira de forma educativa e não afirma dados biográficos não fornecidos.
